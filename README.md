# Diwali Surprise for Nandini ❤️🪔

A romantic, interactive Diwali surprise website created exclusively for Nandini by Ritik.

---

## 🪔 Features

* **Cinematic 7-Screen Experience**:
  1. **The Welcome Experience**: Center realistic glowing diya with animated flame, floating golden starlight, and "Open Your Surprise ✨" button.
  2. **Personal Greeting**: Animated romantic message with glowing typography, floating hearts, and fireworks.
  3. **A Personal Message**: Heartfelt words reminding Nandini how special and cherished she is.
  4. **Our Memories**: Premium photo gallery with touch-friendly cards, high-res fullscreen lightbox with zoom, swipe gestures, next/previous buttons, and keyboard controls.
  5. **A Letter For You**: Digital handwritten love letter on vintage parchment with authentic Hindi & English prose and signature.
  6. **The Final Surprise**: Grand finale with continuous celebratory fireworks, rose petals, and loving sender tribute.
  7. **Replay & Bond**: "Experience Again ❤️" button that seamlessly resets the journey.
* **Canvas Ambient Visuals**: Floating gold dust particles, drifting rose/marigold petals, and celebratory fireworks.
* **Harmonic Ambient Music**: Integrated Web Audio synthesizer playing gentle soothing classical meditative flute/drone scales without external MP3 files.
* **Mobile-First & iPhone Ready**: Fully responsive, safe viewport bounds, and smooth animations.

## 🚀 How to Publish on GitHub Pages (Step-by-Step)

### Step 1: Create a New GitHub Repository
1. Log into your GitHub account: [github.com](https://github.com)
2. Click **New Repository** (+ icon at the top right).
3. Name your repository (e.g., `diwali-for-nandini`).
4. Set it to **Public**.
5. Do **not** initialize with a README (this project already has one).
6. Click **Create repository**.

### Step 2: Upload or Push the Files
Open your terminal / PowerShell in this folder (`C:\Users\ritik\.gemini\antigravity\scratch\diwali-for-nandini`) and run:

```bash
git init
git add .
git commit -m "Romantic Diwali Surprise for Nandini ❤️"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/diwali-for-nandini.git
git push -u origin main
```

*(Alternatively, you can drag and drop all files directly into the GitHub web interface!)*

### Step 3: Enable GitHub Pages
1. In your GitHub repository, click on **Settings** (top tab).
2. In the left sidebar, click on **Pages**.
3. Under **Build and deployment** -> **Branch**, select `main` and `/ (root)`.
4. Click **Save**.
5. Within 1–2 minutes, your website will be live at:
   `https://YOUR_GITHUB_USERNAME.github.io/diwali-for-nandini/`
